# iSIRAJ V1.0

**Cahaya Panduan Kehidupan** — prototaip web app Islam yang responsif.

## Modul
- Home: dashboard dan pautan pantas
- Al-Quran: carian 114 surah dan pautan bacaan luar
- Ibadah: tasbih digital disimpan pada pelayar; waktu solat dan kiblat belum diintegrasikan
- Ilmu: tempat untuk sirah, doa dan hadis yang akan disahkan
- Profil: maklumat versi

## Jalankan
Buka `index.html` dalam pelayar. Tiada build atau dependency diperlukan.

## GitHub Pages
Pergi ke **Settings → Pages → Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, kemudian **Save**.

Alamat yang dijangka: https://khan7-gif.github.io/isiraj/

> Nota: Ini ialah prototaip. Waktu solat rasmi, kompas kiblat, kandungan Al-Quran penuh dan hadis belum tersedia.
